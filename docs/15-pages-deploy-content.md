# Module 11: site pages, deployment pack, content batch

## Privacy, terms, about
`/privacy`, `/terms`, `/about`, linked from the footer. The wording lives in the admin panel "Privacy, terms and about" (blank line = new paragraph; English now, Tamil optional per page). The default text describes what the site really keeps. **Have it read by someone who knows Indian law before launch.** A contact e-mail line appears only after you switch it on and set the address. Switches: `feature.sitePages`, `pages.footerLinks`, `pages.showContact`.

## Deployment pack (`deploy/`)
`README-DEPLOY.md` is a plain step-by-step guide for your Oracle server. The API server can now also serve the built website (`WEB_DIR`), so one small service (port 3100) plus Caddy runs everything. Files: `setup-server.sh` (one time), `update.sh` (after each publish), `backup.sh` (nightly), `studysmart.service`, `studysmart.env.example`, `Caddyfile`. It does not touch chennaideals.in.

## Password help without e-mail
`pnpm --filter @studysmart/api account:reset-password -- parent@example.com` prints a temporary password once and signs the parent out everywhere.

## Content batch (Class 3 maths)
New topics with a lesson (story, explanation, teacher narration with board, worked example, teach-back, quiz, summary) and 12 practice questions each (3 per round, mixed types, a "why wrong" note on every wrong choice):
- Fair Share: Halves and quarters
- Time Goes On: Reading the clock
- Filling and Lifting: Litres and kilograms
- Give and Take: Using rupees

Generated by `tools/author_class3.py` (edit and re-run to change them). Checked by `pnpm --filter @studysmart/api curriculum:check` and by tests (every quiz question exists).

Still needed on these topics: Tamil text (English only for now), a teacher check that each topic fits its NCERT chapter, and recorded teacher audio (`Generate-Lesson-Audio.bat`).
