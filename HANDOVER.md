## 1. What the project is
A free, original, AI-assisted learning website for Indian school students (CBSE now; Tamil Nadu Matric and State Board next). Language: English, with Tamil text/voice planned. No paid services: the build cost must stay ₹0 (domain only). A "Malar Teacher" explains lessons by voice over a picture-first classroom board. No external runtime APIs (only explicit Google/Facebook sign-in). Pipeline philosophy: Understand → Explore → Practise → Explain → Master.

## 3. Tech stack and architecture
- **pnpm monorepo** (Node ≥20, pnpm 9.15): `apps/api` (Express, Drizzle ORM, PGlite for local / PostgreSQL on server, zod), `apps/web` (React + Vite + wouter, vitest tests), `packages/shared` (zod schemas, **settings definitions**, shared types).
- **Content is files**, not database rows: `content/curriculum/cbse-2026-27.json` (class → subject → chapter → topic), `content/lessons/*.json`, `content/questions/*.json`, `content/classroom/*.json` (picture-first classroom scenes), `content/audio/` (voices.json, phrases.json, manifest.json, files/*.mp3), `content/books/`, `content/recipes/` (lesson-compiler recipes). The API loads them at start and imports the curriculum to the DB (`db:seed`).
- **Settings**: every feature has an admin setting in `packages/shared/src/settings.ts` (key, panel, section, label, type, default, `public`, `dependsOn`). The web gets public settings from the API; the admin UI (`apps/web/src/admin/`) renders panels from the same list. Owner rule: **every new feature needs an admin on/off + options**.
- **Admin auth**: `/admin` sign-in with `ADMIN_USER_ID` + `ADMIN_KEY` (server env). Rate limited.
- **Audio**: lessons are spoken from pre-generated MP3 per sentence (`audioKey` = hash of lang+voice+speed+text). `audio:build` calls the voice servers and fills `manifest.json` incrementally (safe to re-run; unchanged text skipped). The browser plays MP3s and highlights words from the word timings.

### Site flow
1. Home (`/`) → class picker (`/:board/:cls`, e.g. `/cbse/6`) → subject (`/:board/:cls/:subject`) → chapter (`.../:chapter`) → topic (`.../:topic`) → `/learn` (LessonPlayer) and `/practice` (questions). Classroom mode: `/classroom/:board/:cls/:subject/:chapter/:topic` (board + narration).
2. Other pages: exam/worksheet/play(games) per chapter, `/term/...` term papers, `/path/...` grade path, `/revise`, `/mistakes`, `/progress`, `/notebook`, `/explore`, `/books` (+ reader `/books/:cls/:file`), `/parent`, `/account`, site pages (privacy/terms/about/faq/…).
3. Search: top-bar `SearchBox` (global, curriculum names, API `/api/v1/curriculum/boards/:b/search`), `/` shortcut, list filters on subject/chapter/notebook/mistakes lists (`FilterBox`). Searching lesson text and reports is NOT built.
4. Access gate (`modules/access`): public vs invite-code private mode. Accounts: nicknames/avatars, optional Google/Facebook sign-in (keys not set yet).
5. Ask-the-teacher tutor (`modules/tutor`): uses lesson text only unless `TUTOR_API_*` env is set (optional, free model).

## 6. How lessons are authored (the generator tooling)
- `tools/lesson-generators/kit2.py` → `T(S,ch,slug,en,story,explain,terms,ex,claim,summary,quiz)` where `S=dict(cls=,subj=,subj_file=)`. It writes `content/lessons/cbse-{cls}-{subj_file}-{chapter}-{topic}.json` and the matching questions file, and appends the topic to the chapter in `cbse-2026-27.json` (the **chapter must already exist**).
- Quiz string formats: `m|stem|right|wrong1|wrong2|explanation` (multiple choice), `t|stem|T-or-F|explanation`, `s|stem|ans1;ans2|explanation` (short answer). Quizzes need plausible distractors; there is a rule that questions on the board show only the visual, not the answer.
- **Slug collision**: a new topic slug equal to an existing one silently overwrites it. After every batch count topics per chapter (`python3 /tmp/show.py CLASS SUBJECT` in the sandbox printed chapters, topic slugs and textbook sections; it reads `toc67.py`).
- `textlesson.py`/`lessonkit.py` = older builders (`gen_sci_*`, `gen_soc_*`). `mark_add.mark(cls,subj,ch,slugs)` appends " (additional, not in the textbook)" to topic name + lesson title (idempotent). `toc67.py` = textbook section lists for Classes 6–7. `prune.py` is deprecated: **never delete off-book topics** (owner rule); keep and label them.
- Validate: `cd apps/api && npx tsx src/tools/check-content.ts` must report no errors (we grep `-ciE "error|invalid|zod"` and expect 0).
- Batch families: `gen3_*`, `gen4_*`, `gen6_*`, `gen7_*` (class-wise); `gen3_santoor.py`, `gen4_evs_eng.py`, `gen67_eng.py` (English story/poem chapters = theme/vocab lessons only because story text wasn't read).
- Classroom scenes (`content/classroom`, 22 so far) are authored by `author_classroom*.py` / recipes + `Build-Lessons.bat`.
