Official Editorial theme, 9 palettes, scroll aids

1. Extract into D:\Smart Learning Website (after the voices patch).
2. Run Add-Institutional-Theme.bat. It stops without changing anything if a file is not what it expects. Undo: copy each *.before-theme file back.
3. Restart the site, Ctrl+F5.
4. Admin > Look and feel: Theme = "Official Editorial", Colour palette = "Indigo & Gold" (or any of the 9 new ones). Nothing looks different until you choose it.
New: reading-progress line and back-to-top button (Admin > Look and feel > Scrolling; both on, each can be switched off).
Fonts: no web fonts are loaded from Google. The theme uses the site's own serif heading style.
