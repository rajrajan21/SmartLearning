# Malar Teacher: assets and licences

This folder is the Malar Teacher speech server and 3D teacher player used by StudySmart.

- **Voice engine**: HeadTTS (MIT) running Kokoro-82M (Apache 2.0). Voices and the model are downloaded on first start; they are not stored in this repository.
- **Teacher avatars** (`public/avatars/*.glb`): generated by `tools/build_avatars.py` from MakeHuman / MPFB2 data. MakeHuman system assets, base mesh and most clothing packs are CC0. Some packs used by the generator are **CC-BY** (for example `bodyparts06_cc-by`, `dress02_cc-by`, `dress03_cc-by`): credit the MakeHuman asset authors listed on makehumancommunity.org when you publish the site.
- **three.js** (`public/vendor`): MIT.
- The asset zip packs themselves are NOT in this repository (large). Download them from the MakeHuman community asset repository if you need to rebuild the avatars.

Run it: `Start Malar Teacher.bat` (installs the engine on first run).
